# Ludopia · Cafe Rush: Idle Tycoon

Public, static promotional and support website. No game source, cloud keys, credentials, or player data belongs in this repository.

## GitHub Pages
Publish `main` / root via Settings → Pages. `.nojekyll` enables plain static hosting.

## Pages
- `index.html`: game introduction
- `privacy.html`: privacy policy
- `terms.html`: usage terms
- `delete-account.html`: deletion requests via support email
- `support.html`: support and FAQs

The game is preparing for Google Play; the homepage deliberately does not claim that a public download is available.

## Operations
The support inbox is `ludo.pia49@gmail.com`. Mail links open the visitor's mail app; this website does not send, record, or automatically process requests. Verify account ownership before acting on requests. Never request passwords or session tokens. Fulfil deletion requests through a separately authenticated admin process; do not add administrative credentials to this website.

Review privacy disclosures whenever data use changes. The game must link to the privacy and account-deletion pages from its account/settings UI before the corresponding release. The existing AAB built before this website has no such links.
